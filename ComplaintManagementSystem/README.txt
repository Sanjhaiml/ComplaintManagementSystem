COMPLAINT MANAGEMENT SYSTEM
Kamaraj College of Engineering and Technology

TECHNOLOGIES:
HTML, CSS, JavaScript, PHP, MySQL

XAMPP SETUP:
1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Copy the ComplaintManagementSystem folder into:
   C:\xampp\htdocs\
4. Open:
   http://localhost/ComplaintManagementSystem/
5. The application automatically creates the database and required tables
   when db.php is loaded. You may also import database.sql in phpMyAdmin.
